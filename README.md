# Python Learning - Automate the Boring Stuff

A structured workspace for learning Python through "Automate the Boring Stuff with Python" by Al Sweigart.

## Structure

```
Python_Block/
├── lessons/       # Chapter-by-chapter exercises (empty folders, ready for your code)
│   ├── chapter_01/
│   ├── chapter_02/
│   ├── ...
│   └── chapter_17/
├── projects/      # Mini-projects from end-of-chapter exercises
├── reference/     # Your personal cheat sheets and reference code
├── main.py
├── pyproject.toml
└── README.md
```

## How to Use

Create `.py` files inside the chapter folders as you work through the book. When you reach a mini-project, put it in the `projects/` folder.
